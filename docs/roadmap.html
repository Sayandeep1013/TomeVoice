The three milestones

Each milestone is checked locally (analyzer and tests) before CI runs, so a build is spent only on finished work.

Milestone 1 · new look and library

Design system, categories, menu, settings, reader polish

  • Fonts: Bodoni Moda for titles, Figtree for interface, Newsreader for the page (Literata and system fonts as options).
  • One theme wired into Flutter, so sliders, switches, dialogs and snack bars stop falling back to stock Material.
  • Bottom navigation: Library · History · More. Browse and Updates join in milestone 2.
  • Categories, list or grid view, sort, long-press multi-select, move books between categories.
  • More: settings, categories, about. Reader settings rebuilt as two tabs, Listen and Read.
  • Reader: fades behind the top and bottom bars, ornament pictures that blend into the page, a voice picker with real names and a preview.
Milestone 2 · web novels

Sources, global search, novel page, reading online and offline

  • LNReader plugin runtime (QuickJS) and source repositories you add by URL.
  • Browse tab: installed sources by language, a source's popular/latest list, search, global search across all sources.
  • Novel page: cover, author, status, summary, chapters; add to a category; read or listen.
  • Chapters fetched as you reach them and kept for offline; listening runs straight across chapters.
  • Bottom navigation becomes Library · Updates · Browse · History · More.
Milestone 3 · updates and moving in

Daily new chapters, downloads, NovelDokusha import, backup

  • Background check (off, 12 h, daily, 2 or 3 days, weekly), Wi-Fi-only and charging-only options, chosen categories.
  • Updates tab and a grouped "N new chapters" notification; optional auto-download.
  • Download queue (next N chapters, a range, all).
  • Import a NovelDokusha backup: novels, read chapters and saved text come across.
  • TomeVoice backup and restore, including categories and sources.
Part 1 · Features

Where novels come from

TomeVoice will run LNReader plugins instead of hand-written scrapers. Each plugin is a small JavaScript file for one site, with four functions: popular novels, search, novel details with its chapter list, and chapter text. Mangayomi, another Flutter app, already runs these plugins in an embedded QuickJS engine, so the approach is proven.

OptionSourcesWho fixes a broken siteVerdict
LNReader plugins in QuickJS319 (183 English)LNReader community, fixes almost dailyChosen
Our own JSON selector rulesWhatever we writeUsToo much upkeep
NovelDokusha's Kotlin scrapers26, half now deadNobody (unmaintained)No

How it fits together:

  • Repositories are added by you, by pasting a URL, the way LNReader and Mihon work. TomeVoice ships no list of sites. That keeps the app clean of the legal trouble that shut down Kotatsu and Legado.
  • Cloudflare: a shared cookie jar plus "Open in browser" to pass a challenge once, as LNReader does. An automatic hidden-WebView retry (Mihon's approach) comes later if needed.
  • A dead site: novels are stored as source id plus path, so a novel can later be moved to another source.

The web-novel flow

  1. Browse → search a name. Every installed source is asked, at most 4 at a time. Each source gets a row of results that fills in as it answers; a broken source shows its error in its own row. Chips: Pinned, Has results.
  2. Novel page: cover, title, author, status (ongoing, completed), summary, genres, chapter list with read marks and newest-first or oldest-first. Buttons: Add to library (asks which category), Read, Listen.
  3. Reading: the chapter is fetched, cleaned (ads, translator notes, dash dividers stripped) and turned into TomeVoice's normal blocks, so highlighting, voices and the sleep timer work as they do for EPUBs.
  4. Listening across chapters: the next 3 chapters are fetched ahead, so audio does not stop at a chapter end.
  5. Share a link to TomeVoice from the browser: it finds the matching source and opens the novel page.

Categories

  • Two defaults, Reading and Later, both renamable. Add as many as you like, reorder by dragging, delete (its books move to the first category).
  • The library shows a tab per category with its book count. Tabs hide when there is only one category.
  • Move books: long-press a book to start selecting, tap more, then Move to…. The book's menu also has Move to….
  • A book sits in one category, matching "move between them". (Mihon allows several; we can add that later if you want it.)
  • New books go to a default category you choose in settings, or "Always ask".
  • Files and web novels share the same categories.

Design system

  • Type: Bodoni Moda (titles, wordmark, chapter openings; italic for the tagline and accents) · Figtree (everything you tap and read as interface; small labels in uppercase with gentle spacing, tabular numbers) · Newsreader (the page).
  • Spacing: 4, 8, 12, 16, 24, 32 only. Corners: 10 (small chips, covers), 16 (rows, fields), 24 (cards, sheets), pill for buttons.
  • Colour: the forest-to-amber ground stays. One accent, amber. Every surface gets a named role (ground, surface, raised, outline) in both light and dark.
  • Components, one of each: section header, setting row, segmented choice, stepper, search field, sheet frame (handle, title, padding), empty state, book cover, badge.
  • Flutter theme: colour scheme, sliders, switches, sheets, dialogs, snack bars, menus, fields and the navigation bar all come from the theme, so nothing falls back to stock Material.

App shell, menu, settings

  • Bottom navigation (Library · History · More now; Updates and Browse in milestone 2), the pattern LNReader and Mihon use. It replaces the bare landing screen.
  • History: books and chapters by when you last opened them, with one-tap resume.
  • More: Categories · Settings · About (version, licences, GitHub). Later: Downloads, Backup.
  • Settings groups: Appearance (theme, fonts) · Reading (text size, line spacing, margins, justify) · Listening (default speed, style, pauses, sleep timer) · Library (default category, view, sort) · About. Milestone 2 adds Sources; milestone 3 adds Updates and Backup.

Library

Now
Big wordmark, Continue card, search, one long list, a floating Add button.
New
Compact header that shrinks as you scroll, with search, view and sort buttons. Continue card. Category tabs with counts. List or grid. Long-press to select and move. Add button stays, frosted.
  • Sort: last read, date added, title, progress. View: list or a 3-column cover grid. Both remembered.
  • Rows: same height for every book; no empty author line; chips for format, language and listening time; web novels show an unread-chapter badge.
  • Landscape: header and Continue card scroll away, so the list gets the screen.

Reader and its settings

The page

  • Soft fades behind the top bar and the player, so text never collides with them.
  • Chapter openings: a small "Chapter 3" label in Figtree and the title large in Bodoni Moda.
  • Ornament pictures (thin, wide, white background) are drawn in the page's ink with the white removed. Real illustrations are untouched.
  • A spoken heading is marked by amber text, not a box.
