# Runtime theme assets

This folder is intentionally empty of image files.

TomeVoice's colour-theme architecture draws grounds as four-stop gradients
(`Skin.groundFor`, `app/lib/theme.dart:142-150`) and page textures in code
(`app/lib/page_tone.dart:224`). Only scene themes load bundled WebP backdrops
(`app/lib/scene.dart:145`, declared at `app/pubspec.yaml:81-86`). The seven
contributed themes are colour palettes, not scenes, so adding a texture or
illustration would require a `pubspec.yaml` edit, a wider dependency surface
and app code to load it — none of which improves a colour-only theme.

The preview PNGs in `../previews/` are documentation artefacts generated by
`app/test/premium_themes_preview_test.dart`; they are not bundled into the app
and are not referenced by `pubspec.yaml`.
