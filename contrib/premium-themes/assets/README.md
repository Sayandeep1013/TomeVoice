# Runtime theme assets

This folder holds notes, not the images themselves. The two scene themes add
portrait WebP backdrops to the app's existing `app/assets/scenes/` folder:

| Asset | Source | Licence |
| --- | --- | --- |
| `app/assets/scenes/gothic.webp` | Paul Vredeman de Vries, "Interior of a Gothic Cathedral" | Public domain |
| `app/assets/scenes/classicRenaissance.webp` | Anthonie Palamedesz., "Interior of a Church Built in the Late-Renaissance Style" (SM 862) | Public domain mark (PDM-owner) |

Both are produced by `tools/scene_art.py` from Wikimedia Commons originals,
cropped and colour-graded to a portrait phone backdrop. They are declared by
explicit path in `app/pubspec.yaml`, loaded once by `SceneGround`, and credited
in `app/assets/licenses/third_party.txt`.

The seven colour themes remain asset-free: their grounds are four-stop
gradients (`Skin.groundFor`, `app/lib/theme.dart`) and page textures are drawn
in code (`app/lib/page_tone.dart`). The preview PNGs in `../previews/` are
documentation artefacts generated by the opt-in preview tests; they are not
bundled into the app and are not referenced by `pubspec.yaml`.
