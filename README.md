# TomeVoice

An EPUB / PDF / ebook reader with text-to-speech, offering a wide range of voices to read books aloud.

## Idea

- Read EPUB, PDF, and other common ebook formats.
- TTS playback with a large selection of voices to choose from.
- Ship as a Windows desktop app (.exe) and a mobile app (.apk).
